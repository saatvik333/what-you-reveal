Browser Fingerprinting Analysis Categories

What You Reveal performs real-time detection of 15 fingerprinting vectors to show what your browser exposes to websites. All analysis happens locally in your browser.

  • Privacy Mode and Tor Network Detection
  • Network Information and IP Address Detection
  • Device Hardware Analysis (CPU, GPU, Memory)
  • Screen and Display Metrics
  • Client Hints and User Agent Analysis
  • Navigator Object Variables
  • Intl API Locale Fingerprinting
  • Font Library Detection and Fingerprinting
  • WebGL Renderer and GPU Identification
  • Digital Identity Hash (Canvas, Audio, Emoji)
  • Media Device Enumeration
  • Audio and Video Codec Detection
  • Browser Permission Status
  • Clipboard Access Detection
  • Bot and Automation Integrity Scanning
